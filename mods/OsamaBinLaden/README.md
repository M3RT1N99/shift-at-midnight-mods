# Osama Bin Laden NPC

Work-in-progress *Shift At Midnight* mod for a satirical single-player monster NPC. At
the start of a Hunt it appears at a Hunt spawn point, runs toward the local player while
screaming and detonates at close range. Damage falls off to zero at the configured blast
radius.

The current character, scream and explosion are all generated by the plugin at runtime:
the character is a deliberately simple low-poly figure and both effects are local. The
mod contains no photograph, recording, model, texture or extracted game asset.

> **Status:** functional MVP. Debug and Release builds compile against the verified game
> assemblies and the pure logic smoke tests pass. Hunt gameplay still needs an in-game
> playtest before this should be treated as a stable release.

## Safety boundary

This mod is deliberately single-player-only. The implementation must check the active
Fusion session before it creates any object, disable itself when multiplayer is active,
and remove its local runtime objects if the session changes. It must never send an RPC or
reliable-data message.

No portrait, model, texture, audio clip, game asset or third-party executable is included.
The plugin builds its visuals and original PCM scream in memory.

## Behaviour and configuration

- Watches `HuntManager.huntInProgress` and makes at most one spawn attempt per Hunt.
- Uses the farthest eligible Hunt spawn point, with a local fallback behind the player.
- Pursues only `ClientPlayer.Instance.playerMan` and starts a short fuse at close range.
- Re-confirms solo mode immediately before calling the game's `PlayerManager.TakeDamage`.
- Removes every object on Hunt end, scene change, multiplayer/unknown session state, or
  loader shutdown.

Settings live in `UserData/OsamaBinLaden/config.json`. Spawn chance, distances, speed,
fuse, lifetime, volume, scale, blast radius and damage are bounded when loaded. The
single-player and no-network declarations are locked safety invariants, not opt-outs.

## Development

Install MelonLoader 0.7.3+ into the real Steam installation and launch the game once so
`MelonLoader/Il2CppAssemblies` is generated. Compile without deploying with:

```powershell
./mods/OsamaBinLaden/scripts/build.ps1 -Configuration Debug -NoDeploy
```

Run the Unity-independent checks with:

```powershell
dotnet run --project ./mods/OsamaBinLaden/tests/OsamaBinLaden.SmokeTests.csproj
```

See `docs/DEVELOPMENT.md` for the remaining in-game verification gates.
