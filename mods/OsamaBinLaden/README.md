# Osama Bin Laden NPC

Work-in-progress *Shift At Midnight* mod for a satirical monster NPC. At the start of a
Hunt it appears at a Hunt spawn point, runs toward its target while screaming and
detonates at close range. Damage falls off to zero at the configured blast radius. Works
solo, and host-authoritatively in multiplayer.

The current character, scream and explosion are all generated by the plugin at runtime:
the character is a deliberately simple low-poly figure and both effects are local. The
mod contains no photograph, recording, model, texture or extracted game asset.

> **Status:** functional MVP, now with multiplayer wired up. Debug and Release builds
> compile against the verified game assemblies and the pure-logic smoke tests pass. Hunt
> gameplay, in both solo and multiplayer, still needs an in-game playtest before this
> should be treated as a stable release.

## Safety boundary

The implementation must positively confirm the active Fusion session before it creates
any object, in both solo and multiplayer, and fails closed - it disables itself - on any
ambiguous or unknown session state. It must remove its local runtime objects immediately
if the session changes.

In multiplayer, only the Fusion **host** ever simulates the encounter and calls the
game's `PlayerManager.TakeDamage`; every other player only ever renders a cosmetic mirror
of the host's character, built from the messages it receives. A player is only ever
eligible as a target - host included - after completing a lightweight handshake that
proves they run this mod; a player without the mod (or with it disabled) is never
targeted and never receives a message, so unmodded players are unaffected by design.
Every message is a bounded, versioned reliable-data frame sent over Fusion's own
channel - never a raw socket, never a Fusion object spawn, never a write to a replicated
object. See `docs/DEVELOPMENT.md` for the full handshake and message-authority design.

Single-player-only behaviour remains available as an explicit opt-out
(`singlePlayerOnly` / `safety.disableInMultiplayer` in the config), and
`safety.allowNetworkSends` is a separate, honoured "never send anything" switch.

No portrait, model, texture, audio clip, game asset or third-party executable is included.
The plugin builds its visuals and original PCM scream in memory.

## Behaviour and configuration

- Watches `HuntManager.huntInProgress` and makes at most one spawn attempt per Hunt.
- Uses the farthest eligible Hunt spawn point, with a local fallback behind the target.
- In solo, pursues only `ClientPlayer.Instance.playerMan`. In multiplayer, the host picks
  one eligible target (itself or a validated peer) and every mirror pursues that same
  player's transform.
- Starts a short fuse at close range and re-confirms authority immediately before calling
  the game's `PlayerManager.TakeDamage` - solo mode a second time, multiplayer against
  fresh Fusion state for the exact player and object the encounter targeted.
- Removes every object on Hunt end, scene change, an ambiguous/unknown session state,
  disconnect of the current target, or loader shutdown.

Settings live in `UserData/OsamaBinLaden/config.json`. Spawn chance, distances, speed,
fuse, lifetime, volume, scale, blast radius, damage and multiplayer handshake/heartbeat
timing are all bounded when loaded.

## Development

Install MelonLoader 0.7.3+ into the real Steam installation and launch the game once so
`MelonLoader/Il2CppAssemblies` is generated. Compile without deploying with:

```powershell
./mods/OsamaBinLaden/scripts/build.ps1 -Configuration Debug -NoDeploy
```

Run the Unity-independent checks with:

```powershell
dotnet run --project ./mods/OsamaBinLaden/tests/OsamaBinLaden.SmokeTests.csproj
```

See `docs/DEVELOPMENT.md` for the remaining in-game verification gates.
